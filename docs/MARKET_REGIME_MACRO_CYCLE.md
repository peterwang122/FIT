# 市场环境轻量日更与宏观周期数据

状态：研究阶段，模型未批准。本文记录采集、时点和运行边界，不代表新的牛熊规则已经上线。

## 目标与边界

- 中证全指用于观察全A主环境，沪深300和中证1000用于观察指数适配。
- 日频市场参与度使用沪深300、中证500、中证1000的均线参与比例，是指数代理，不是个股广度。
- 新数据只进入研究快照和只读证据接口，不修改既有市场环境判定、策略、停买、交易或通知。
- 月度数据只在正式发布后更新。没有新公告是正常结果，不视为采集失败。

## 官方来源与口径

采集端只保存官方原值、官方发布时间、实际可用时间、来源URL、原始响应、解析器版本和首次留存时间。

| 类别 | 来源 | 主要序列 |
| --- | --- | --- |
| 货币与信贷 | 中国人民银行金融统计报告、货币供应量统计表 | M1、M2、居民及企业贷款结构 |
| 社融 | 中国人民银行社融存量、增量报告及月度统计表 | 存量、增量、政府债、人民币贷款、企业债等分项 |
| 景气 | 国家统计局月度公告 | 制造业PMI、生产、新订单、非制造业商务活动 |
| 物价 | 国家统计局月度公告 | CPI、核心CPI、PPI同比及环比 |
| 盈利 | 国家统计局工业企业利润公告 | 利润、营业收入累计值和官方增速、官方当月利润增速 |

M1按口径分段保存：

- `m1_legacy`：2024年12月以前的旧统计范围。
- `m1_2025`：2025年1月起的新统计范围，以及人民银行公布的2024年可比数据。
- 不跨口径计算变化，不自行平滑或拼接。

社融总量和政府债券独立保存。`剔除政府债券社融增量`仅是研究派生指标，不称为私人部门信用。工业利润累计金额不机械相减成当月同比。

## 版本与时点

- `cn_macro_release`保存公告版本、发布时间、可用时间、原始响应及解析版本。
- `cn_macro_observation`保存每个公告版本对应的观测值；修订和解析纠错追加新版本，不覆盖旧值。
- `cn_macro_collection_checkpoint`保存断点及失败原因。
- 严格时点查询同时要求公告已经发布且该版本已经被系统留存。后补的历史公告可以展示，但不能倒推成过去已经知道的数据。
- 只有发布日期没有具体时间时，保守按次日00:00可用。

截至2026-09-21完成的官方覆盖并不等长：

- M1/M2官方表最早稳定覆盖到2006-06；M1新口径可比数据从2024-01开始。
- 社融月度增量及主要分项从2015-01开始，政府债券分项从2019-01开始。
- 当前国家统计局网页目录可稳定解析的PMI、CPI、PPI从2021-10开始。
- 工业企业利润累计序列从2021-09开始，官方当月利润增速从2024-08开始。
- 不为追求2005年以来的整齐曲线而估算或使用非官方拼接值；页面和报告按序列披露起点、缺口和制度性不发布月份。

## 日更任务

- `宏观周期数据检查`：每天21:40运行，包括周末。检查近期公告和修订，幂等保存；访问或解析失败明确失败。
- `市场环境轻量更新`：A股交易日22:45运行。只定向校验中证全指、沪深300、中证500、中证1000，并生成研究快照。
- 快照位置：`runtime/reports/market_regime/lightweight.json`；每次成功发布同时保留带截止时点的归档文件。
- 快照失败时不覆盖上一份成功结果。

采集端命令：

```bash
python run.py macro-cycle daily [YYYY-MM-DD]
python run.py macro-cycle backfill 2005-01-01 [END_DATE]
python run.py macro-cycle repair
python run.py market-regime daily [YYYY-MM-DD]
```

## 回退与验收

- 回退任务定义和只读接口不会删除官方原始数据或历史版本。
- 正式启用前必须验证：未来公告不可见、M1口径不混合、月度沿用不增加样本、修订不改写旧截止时点、缺失不当作正常值。
- 研究结果必须分别报告趋势、趋势加指数参与度、再加入资金和宏观证据的增量，不根据已知牛熊拐点反向调权。
