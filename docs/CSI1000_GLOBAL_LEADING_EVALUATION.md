# 中证1000全球风险前兆历史评估

## 评估口径

- 数据区间：2023-09-15至2026-08-25。
- 信号日只使用当日22:30前已经公开的数据；外盘数据按`available_at`映射。
- 国内脆弱积累分不低于60时，全球风险前兆才可生效。
- 波动率重定价路径按0/50/100组件分计分，路径分不低于75时触发。
- 亚洲/新兴市场路径优先使用严格市场广度；当区域命中达到3项、七市场已有2个实际市场承压且压力数量位于历史80%分位以上时，允许区域波动率先行确认。
- 信号日收盘确认，`decision_date`为下一A股交易日。
- 最大跌幅以信号日中证1000收盘价为基准，使用后续指数日内最低价计算。

## 结论

- 8段事件中，7段在随后10个交易日出现至少3%的日内最大回撤。
- 8段事件全部在随后20个交易日出现至少3%的日内最大回撤。
- 6段在随后20个交易日出现超过5%的日内最大回撤。
- `2024-07-25`是当前样本中的弱预警：前10个交易日没有出现3%回撤，第20个交易日才达到-3.20%。因此不能把“8段全部在10日内回撤3%”写成已验证事实。
- 样本只有8段，结果用于风险管理提示，不应解释为可独立交易的买卖信号。
