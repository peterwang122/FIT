## 本轮原因

原模型把极端当天全覆盖和累计亮色比例作为主要约束，遗漏了连续信号段的长度。牛市蓝色曾连续274个交易日，熊市红色曾连续195个交易日。它们更接近环境状态，不是合格的波段择时结果；原报告和策略记录保留作对照，不能把原交付状态视为本轮获准继续使用。

## 研究契约

- 全部历史仍是开发数据，不重新划分训练、验证或样本外。牛熊大周期标签只用于评价，不进入实时规则。
- 长历史候选必须在2022年以前已完成预热。期权候选使用510500与159922各自真实可用期，原值和滚动分位的起点分别披露，不混为一个“完整起点”。
- 低位和高位组成一套模型时，必须从两端共同可用日起重新评价。不能拿2026年才出现的高位因子与2023年的低位表现拼成一套历史。
- 日频分位继续使用此前最多1260个有效观测、至少252个样本，排除当日；22:30截止，次一实际交易日开盘执行。缺失不补50或0。
- 新增准入检查：2022起实际绘制区间任何同色段最多7个交易日；所属环境区域长度中位数不超过2日；每种颜色不超过所属环境交易日的20%。这些是拒绝条件，不是事后强行剪断曲线。
- 每端至少8个完整20日评价区域，其中2022起至少4个；不能靠单个成功案例获胜。
- 普通5%反转波段采用首次信号距事后极值前5至后3个交易日评价，覆盖率至少50%。一个几个月前开始的长色段不能冒充命中后来的拐点。
- 仍保留原计划的同日极端覆盖要求，若与短信号和逆向风险冲突，明确报告未找到合格候选，不悄悄放宽。
- 复核各分支的中证500自身价格位置，剔除拿期权计算输入的无风险利率、行权价、样本数冒充保护需求的规则。总样本中先达到有利5%的比例不能低于先达到不利3%的比例。
- 先单因子扫描全部原有特征，再开展有界组合；另对融资、可知时点核心情绪、IC、银行、全球压力、两来源500ETF期权逐项执行价格位置和转向组合，避免单因子排名使重要数据失去组合研究机会。
- 参数、尝试、拒绝理由和源数据指纹均留存。这仍是历史优化，不能声称以后每个极端必定命中，也不能把有界搜索失败称为数学上不存在合格策略。

## 命令与交付边界

```bash
python scripts/research/csi500_coverage_restudy.py
python scripts/research/extend_csi500_coverage.py
python scripts/research/review_csi500_coverage.py
```

输出在`runtime/reports/csi500_coverage_restudy`，复用上轮冻结的只读特征快照，不重复采集或回补。原单因子/组合尝试与定向扩展分别保存，完整性由行数核验；非写日志的分析上下文不得覆盖原尝试文件。

`review.json`记录最终准入状态，`report.md`给出人读说明。标为`no_qualified_pair_do_not_install`的组合不得写入策略中心；`research_candidate_only`也不等于已通过接口、筛选、交易回测和页面的一致性验收。

本轮研究脚本不写数据库，不创建或覆盖策略，不变更中证1000、市场环境、通知、采集、服务或VPN，不提交或推送远端。正式发布需在确认按覆盖期独立策略还是保留两条可用期分支后，对通过准入的整套模型另行完成现有引擎回测、副图与筛选一致性和浏览器核验。
