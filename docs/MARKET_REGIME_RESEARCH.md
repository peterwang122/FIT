版本：research-v1，2026-09-06。离线研究、视觉预览已完成；用户确认布局后已实现只读页面，模型仍未通过验收。

## 边界

- 新模块位于宏观内部导航 `/macro/market-regime`，不改变抬头、侧栏、色系。
- 正式页面与 API 只展示离线研究快照，没有数据库迁移、策略配置修改、新任务或通知。
- 中证全指为市场参照，中证1000为策略目标；两者分开判断，不以全市场标签代替目标状态。
- 停买不是卖出。测试仅限制新买入额度，不自动清仓，不改变原蓝色卖出条件。
- 既有“高点测试”替换卖出规则仅作为独立研究组合，不写回保存的策略。

## 固定候选规则

所有日线条件在收盘后确认，次一真实交易日开盘执行。MA包含当日已经完成的收盘值。

| 条件 | 研究基准 |
| --- | --- |
| 临时暂停 | 指数低于MA60，且可评估股票中高于MA60者不足40%，连续3个交易日 |
| 假设失效 | 指数低于MA120、MA120低于20个交易日前、高于MA120股票不足30%，连续10日 |
| 修复观察 | 指数高于MA60，且高于MA60股票至少50%，连续5日；恢复原买入额度的50% |
| 环境有效 | 修复条件加指数高于MA120、MA120不再下降、MA120广度至少50%，连续5日 |
| 数据不足 | 必需数据缺失、少于500只当日交易股票或MA120有效股票不足当日交易股票60%；不输出允许买入 |

假设失效状态不因条件短暂消失解除，必须满足修复条件；缺失日不视作解除，但打断连续确认计数。
首次积累足够样本后从修复观察开始，不事后假设初始是牛市。

比较四个预先固定候选：仅慢失效（关闭临时暂停）、基准60日、40日、80日。
40/80日仅做速度敏感性检查，其他阈值不变。不得看结果后选择最漂亮年份重新调参。
2005–2023与2024以后分开报告；后者已经在前期讨论中被观察过，不称为严格未见样本。

## 数据审计门槛

- 指数使用库内原始日线，不填补价格或假设工作日。中证全指缺失日已另从官网定向回补。
- 初查的新后复权表覆盖不足，随后发现旧 `stock_data` 的后复权历史；本轮策略结果使用该旧表，统一截止2026-03-13。未复权 `stock_daily_data` 探索未通过验收，**不得用于结论或上线广度**。
- 股票范围来自历史行情内实际存在的代码，不用当前上市名单过滤；这只能避免主动剔除退市股，不能证明历史退市覆盖完整。
- 只统计当日有正价格且成交量大于0的股票。均线要求对应市场日历窗口完整；不填停牌价格，不用新股未来数据。
- 每日保留观察数、交易数、可评估数及排除比例；所有来源、批次、日期覆盖留档。
- 未复权除权跳空可能造成假跌破，因此不与旧后复权序列拼接。复权来源版本和历史股票范围验收通过前，报告与预览明确“研究数据，未获准接入”。
- PMI、M1/M2、私人部门信用及盈利广度没有完成公告时间与历史版本核验，不虚构评分。银行流动性先作为解释数据，不承担买卖门槛。
- 现有全球风险序列只做覆盖审计。全球条件尚未独立验证，不在本轮悄悄加入优化收益。

## 验收输出

1. 全历史逐日环境、各年暂停比例、每段暂停后的5/10/20/60日最差与最好区间。
2. 不只统计大跌命中，也输出暂停后上涨的段落、数据不足和未完成的未来窗口。
3. 原“情绪强化测试”与“原低点+高点测试”的无门槛、各门槛比较，保持其相应买卖额度不变。
4. 逐笔受限红信号、次日执行、收益、收盘最大回撤、平均仓位；包含零成本与单边10bp敏感性。
5. 不用长期指数择时收益代替情绪策略收益，不用后来的实际牛熊分界生成状态。
6. 官方历史修订、情绪估算/回补值、融资发布时间等既有输入限制继续披露。

## 已确认页面与只读接口

- 页面：`/macro/market-regime`。两个观察指数共用页面，分别读取自己的K线和候选状态。
- 接口：`GET /api/v1/macro/market-regime`，沿用宏观模块登录认证；可传 `index_code`、`start_date`、`end_date`。
- 快照：`runtime/reports/market_regime/report.json`，不含用户、策略配置、凭据。首次请求解析，按文件路径、修改时间和大小缓存；原子替换后自动重新读取，无需重启。
- 页面一次获取所选指数完整历史，初始显示2024-09-18至最新价格日。缩放、悬停、点击历史日期不再请求接口；切换指数取消旧请求，避免迟到结果覆盖。
- 悬停只更新摘要和右侧复盘；点击K线、事件或日期输入才锁定底层证据。移出K线恢复锁定日，重复点击同一事件也会重新定位。
- 价格覆盖与广度覆盖分别显示。2026-03-13以后的广度和股票覆盖数为空，不伪造为零；个别指数日仅收盘价可用时，保留收盘但K线留空，不填造开高低。
- `generated_at` 是快照生成时间，不是行情日期，也不代表已具备自动日更。本次没有添加定时生成或接入策略的代码。
